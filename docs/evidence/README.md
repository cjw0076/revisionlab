# Historical evidence receipts

These JSON files are preserved copies from the recovered original v13 experiment. Treat them as read-only historical receipts, not new release benchmark output.

- `SUMMARY.json`: recorded policy metrics across five weight seeds.
- `INDEPENDENT_VERIFICATION.json`: recorded independent replay checks and scoped comparisons.
- `SELECTION_LOCK.json`: recorded experiment selection lock.
- `v13-source-sha256.json`: recovered source/result file hashes.

See [provenance](../provenance.md) for recovery location, exact receipt hashes, and limitations. The wheel contains package code and typing metadata; it does not include these receipts, raw weather data, or historical checkpoints.
